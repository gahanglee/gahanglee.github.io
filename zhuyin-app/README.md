# 注音小學堂(設計原型)

平板橫式(1280×800)的注音符號學習 App 原型。入口:`Main.dc.html`(經由 `index.html`)。

## 畫面
- `Main.dc.html` 學習地圖(11 關,含聲調)
- `Learn.dc.html` 符號學習(筆順動畫、發音、例字、嘴型提示)
- `Game.dc.html` 聽音選字(可切換關卡、過關畫面)
- `Parent.dc.html` 家長專區(關卡掌握度、星星、學習時間、徽章)

進度資料存在瀏覽器 localStorage,各畫面彼此共用。
