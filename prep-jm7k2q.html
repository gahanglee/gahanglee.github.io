Q1 請簡單自我介紹 / 為什麼想當學前特教巡迴老師?
背景一句 → 專長一句 → 動機扣「巡迴/融合」→ 承諾一句
• 背景:碩士主修輔助科技、正修習師資職前教育課程。
• 專長:把特教理論做成現場能用的工具 — 多感官輔具、情緒教育 App、合理調整手冊。
• 動機:巡迴輔導能把支持帶進每個孩子的自然情境(幼兒園、家庭),這正是我想做的「把專業送到孩子身邊」。
• 承諾:我擅長跨專業協作與工具化,能減輕普師負擔、讓融合真的發生。
Q2 你的教育理念是什麼? 必考
一句核心信念 → 兩個支柱 → 一個具體展現
• 核心:每個孩子都有能力,老師的責任是「調整環境與方法」,而不是要求孩子先達標。
• 支柱一(融合/UDL):用通用設計降低參與門檻,讓特殊需求幼兒和同儕一起學。
• 支柱二(正向/賦能):以正向行為支持與情緒教育(RULER)看見孩子的需求而非問題。
• 展現:我寫的合理調整手冊,就是把「調整環境」這個信念變成 20 張現場能用的資訊卡。
Q3 學前特教「巡迴輔導」的服務內容/模式有哪些?你會怎麼做? 專業核心
直接服務 + 間接服務 + 諮詢 + 親師合作
• 直接服務:入班協同教學、抽離/外加的個別或小組指導。
• 間接服務:為普通班老師示範教學策略、調整教材教具、環境規劃。
• 諮詢:對普師、家長提供特教專業建議(行為、溝通、IEP 目標)。
• 親師合作:定期溝通、家庭本位建議,讓策略延伸到家中。
關鍵詞:入班協同示範教學諮詢IEP自然情境
Q4 遇到有情緒行為(如哭鬧、攻擊)的幼兒,你怎麼處理?
當下安全 → 找功能 → 正向支持 → 教替代行為
• 當下:先確保安全與情緒穩定,不在情緒高點說教。
• 分析:用功能性行為評量找「行為背後的需求」(逃避、獲得、感官、注意)。
• 支持:調整前事(環境/作息)、教孩子可用的替代行為與溝通方式。
• 案例:我做的情緒小島 App 就是用「我覺得→我想要→我可以」帶孩子辨識並表達情緒,取代發作。
Q5 如何與普通班老師/家長合作?若普師不配合怎麼辦?
同理 → 減負 → 具體可行 → 小步成功
• 先同理普師的班級壓力,把自己定位成「幫手」不是「督導」。
• 提供能減輕負擔的具體做法(現成教具、一句話策略),而不是加作業。
• 從一個小改變開始,看到成效後再擴大,建立信任。
• 對家長:多報喜、用他們聽得懂的話說明 IEP 目標與在家可做的一件小事。
Q6 什麼是合理調整 / UDL?請舉例。
• 合理調整:依個別需求調整環境、方式、評量,讓身障者能公平參與(CRPD 精神)。
• UDL:一開始就設計「多元表徵、多元參與、多元表達」,讓最多孩子不需額外調整就能學。
• 例:指令同時給口語+圖卡(多元表徵)、允許用指、貼、說多種方式回應(多元表達)。
你的加分:我把這些整理成一本幼兒園合理調整手冊,老師翻開就能用。
Q7 如何運用輔助科技/教具幫助特殊需求幼兒?
• 原則:先評估需求,再選工具,科技是手段不是目的。
• 案例:我做的多感官輔具用語音辨識 + 燈光回饋,鼓勵低口語幼兒開口,把「說話」變成有趣的互動。
• 低科技也重要:圖卡、作息表、視覺提示同樣是輔助科技的一環。
Q8 情境題:巡迴到園發現孩子的 IEP 目標不合適,你會怎麼做?
• 蒐集現況資料(觀察、普師與家長回饋)→ 召開/建議召開 IEP 會議 → 依孩子現況滾動修正目標 → 記錄追蹤。強調資料本位、團隊決策。
📌 收尾金句(任何題都能扣):「我會持續觀察、和團隊一起調整,把支持帶到孩子的自然情境裡。」— 展現巡迴輔導的核心精神。
